# Vendor-Patch-Spoof-Basic
Simple Basic module.prop, system.prop and auto_mount files to spoof "Vendor Security Patch" In settings and in Trust in AOSP roms.
I update this to the latest security patch number as soon as im able to get a device with the latest Platform update.
Current Patch Date: 11-01-2026
Works on Magisk, KernelSU, Apatch.
Note: Sometimes this module may not work, if it doesnt, Im not really sure of a fix.
